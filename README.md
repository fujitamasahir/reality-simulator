# Reality Simulator

**Experience anything. Learn by doing. Prove your skills.**

[Play the web demo](https://fujitamasahir.github.io/reality-simulator/)

People learn through work, experimentation, failure, and interaction. Yet the experiences they need to grow do not always occur at the right time.

Reality Simulator turns learning into interactive workplace experiences. In this MVP, become a robotics engineer, investigate a humanoid robot's faults, review evidence, make decisions, and receive personalized follow-up assignments and a performance report.

Traditional adaptive learning optimizes which question a learner should answer next. Reality Simulator aims to optimize which **experience** a learner should have next.

Our long-term goal is to generate experiences from any learning material with AI, maximize practical knowledge gained per unit of time, and offer verifiable skill certificates that help learners demonstrate their abilities to employers.

**Current MVP:** one curated robotics scenario with rule-based adaptive routing. No account, API key, or paid LLM is required. AI-generated worlds and verified certificates are future features.
